# Manual test — Sprint 8.1 — #133 Local Proxy w/ root CA [USER, cross-platform]

Companion to issue #133's Manual AC. Cross-platform USER smoke (macOS + Linux + Windows).

## Parent 1 — Pre-flight (per platform)

Sub-step 1.1 — Build proxy package

  Action:    `npm -w proxy run build` from repo root.
  Expected:  Exit 0; `proxy/dist/index.js` exists.
  Verify via: shell.
  Run:       `npm -w proxy run build && ls proxy/dist/index.js`

Sub-step 1.2 — Generate root CA

  Action:    Run the generator script.
  Expected:  Exit 0; `proxy/certs/root-ca.crt` created.
  Verify via: shell.
  Run:       `node proxy/scripts/generate-root-ca.js`

Sub-step 1.3 — Start proxy

  Action:    `node proxy/dist/index.js --port 8443` in a dedicated terminal.
  Expected:  Proxy listens on 8443.
  Verify via: shell stdout.
  Run:       `node proxy/dist/index.js --port 8443`

## Parent 2 — macOS leg

Sub-step 2.1 — Install root CA via Keychain

  Action:    Open Keychain Access; drag `proxy/certs/root-ca.crt` into System keychain; mark "Always Trust".
  Expected:  Cert listed; trusted.
  Verify via: Keychain Access UI.
  Run:       (manual)

Sub-step 2.2 — Configure macOS system proxy

  Action:    System Preferences → Network → Advanced → Proxies → enable HTTPS proxy at `localhost:8443`.
  Expected:  Saved.
  Verify via: System Preferences UI.
  Run:       (manual)

Sub-step 2.3 — Smoke `curl https://example.com`

  Action:    Run curl.
  Expected:  Exit 0; response 200; no cert warning.
  Verify via: shell exit + stdout.
  Run:       `curl -v https://example.com`

## Parent 3 — Linux leg

Sub-step 3.1 — Install root CA

  Action:    `sudo cp proxy/certs/root-ca.crt /usr/local/share/ca-certificates/honeyllm.crt && sudo update-ca-certificates`.
  Expected:  Cert added to trust store.
  Verify via: shell exit.
  Run:       `sudo update-ca-certificates`

Sub-step 3.2 — Configure proxy environment

  Action:    Export `https_proxy=http://localhost:8443` in current shell.
  Expected:  Var exported.
  Verify via: shell.
  Run:       `export https_proxy=http://localhost:8443 && env | grep proxy`

Sub-step 3.3 — Smoke curl

  Action:    Run curl.
  Expected:  Exit 0; response 200; no warning.
  Verify via: shell exit + stdout.
  Run:       `curl -v https://example.com`
