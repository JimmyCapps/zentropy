# Manual test — Sprint 1.4 — #217 Officeworks renderer leak

Companion to issue #217's Manual AC. `/quantrix:guide 1.4` walks parent steps one at a time, ≤10 sub-steps each.

## Parent 1 — Pre-flight

Sub-step 1.1 — Confirm clean build

  Action:    `npm run build` from repo root.
  Expected:  Exit 0; `dist/` populated.
  Verify via: shell exit code.
  Run:       `npm run build`

Sub-step 1.2 — Load extension unpacked

  Action:    `chrome://extensions/` → Developer mode ON → Load unpacked → select `dist/`.
  Expected:  HoneyLLM appears in extension list with no error badge.
  Verify via: `chrome://extensions/` row.
  Run:       (manual click)

Sub-step 1.3 — Reload after build

  Action:    Click reload icon on the HoneyLLM card.
  Expected:  Extension restarts; service-worker chip shows "active".
  Verify via: `chrome://extensions/` row.
  Run:       (manual click)

## Parent 2 — Officeworks homepage idle bound

Sub-step 2.1 — Open Chrome Task Manager

  Action:    `Window` → `Task Manager`.
  Expected:  Task manager opens.
  Verify via: `browser:task-manager`.
  Run:       (manual menu)

Sub-step 2.2 — Navigate to Officeworks homepage

  Action:    Open new tab, go to `https://www.officeworks.com.au/`.
  Expected:  Homepage loads; HoneyLLM scan completes within ~30s.
  Verify via: `popup:verdict`.
  Run:       (manual)

Sub-step 2.3 — Capture renderer baseline T=0

  Action:    Note the Officeworks tab renderer's PID + Memory + CPU columns at scan-complete.
  Expected:  Memory and CPU values recorded for delta comparison.
  Verify via: `browser:task-manager` row matching tab PID.
  Run:       (manual record)

Sub-step 2.4 — Idle for 5 minutes

  Action:    Leave tab untouched. Do not interact, scroll, or refocus.
  Expected:  5 minutes elapse.
  Verify via: wall clock.
  Run:       (manual wait)

Sub-step 2.5 — Capture renderer at T=5min

  Action:    Note the same tab renderer's Memory + CPU columns.
  Expected:  Renderer RSS < 1.5 GB; CPU returns to <10% within 60s of idle.
  Verify via: `browser:task-manager`.
  Run:       (manual record)
