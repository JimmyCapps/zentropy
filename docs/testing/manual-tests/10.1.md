## Parent 3 — Cap + clear

Sub-step 3.1 — Force-prune trigger (60 messages × 51 conversations)

  Action:    Generate 51 conversations (each with 1+ messages); the 51st should evict the oldest.
  Expected:  Storage holds at most 50 conversation keys.
  Verify via: `popup:chat-tab` + service-worker console.
  Run:       (manual)

Sub-step 3.2 — Close popup; reopen

  Action:    Close popup; reopen via toolbar icon.
  Expected:  50 most-recent conversations visible; oldest one absent.
  Verify via: `popup:chat-tab`.
  Run:       (manual)

Sub-step 3.3 — Confirm storage shape

  Action:    Run the storage get.
  Expected:  ≤ 50 keys matching `honeyllm:chat:*`.
  Verify via: `service-worker:console`.
  Run:       `Object.keys(await chrome.storage.local.get(null)).filter(k => k.startsWith('honeyllm:chat:')).length`

Sub-step 3.4 — Click "Clear all chats"

  Action:    Click the clear button in chat tab.
  Expected:  Empty state shown.
  Verify via: `popup:chat-tab`.
  Run:       (manual)

Sub-step 3.5 — Confirm storage cleared

  Action:    Run the storage get again.
  Expected:  Zero `honeyllm:chat:*` keys.
  Verify via: `service-worker:console`.
  Run:       `Object.keys(await chrome.storage.local.get(null)).filter(k => k.startsWith('honeyllm:chat:')).length`
